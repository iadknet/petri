# Security Policy

## Supported branch

Security reports are accepted for the current default branch, `main`. Other
branches and historical revisions are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include live
credentials, tokens, keys, or other secrets in a report.

While this repository is private, email a sanitized report to
[isaac@iadk.net](mailto:isaac@iadk.net). GitHub private vulnerability reporting
is not currently enabled.

Include the affected commit or branch, a concise description of the impact,
and safe reproduction steps or a minimal proof of concept.
