# AGENTS.md

Repository-wide instructions for coding agents.


## Mandatory Rust Skill Gate

- For any Rust-related task, you MUST load `rust-skills` before doing any work.
- Rust-related tasks include:
  - writing, editing, or reviewing `.rs` files
  - changing Rust crate configuration, tests, or public APIs
  - evaluating Rust architecture, performance, safety, or idiomatic style
- Do not begin Rust implementation or Rust review until this gate is satisfied.

## Instruction Layering

- Root policy applies across the repository.
- Additional `AGENTS.md` files in subdirectories add local constraints.
- When instructions conflict, use the most specific in-scope file.
