## Intent review

The conversations that established or changed the affected requirements are
exported at `{{INTENT_EXPORT}}`. In an Intent section, reconcile each distinct
user goal, premise and decision with its owning row or design-note requirement
by a short source quote; check that the planned behavior reaches the code
routes the requirement covers; verify material assistant claims about the
code; and separate user choices from planner or reviewer proposals. The
planner chose which conversations to export: report a requirement whose
source conversation the export lacks as unverified.
