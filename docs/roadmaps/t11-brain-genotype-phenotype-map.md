# T11 — Brain Genotype-Phenotype Map

**Status**: In Progress
**Last updated**: 2026-09-06
**Master**: [Program Roadmap](../roadmap.md)

## Goal

Petri's brain is a heterogeneous mesh: nodes of any compute kind that read
sensors, shared memory, and an upstream bus, steer which node runs next, may
write memory as a side effect, and commit one action or a queue each tick.
Make the map from that genome to behavior evolvable: a brain can gain an
instruction, a node, an edge, or a memory motif and usually still act as its
parent did, so lineages accumulate structure through neutral and near-neutral
steps, and remembered state advances on a clock the world sets. Write the
properties that make this true as the contract every node kind must meet,
repair the existing VM and graph kinds against it first, and change a
representation only where the neighborhood reading still shows a gap.

## Track Success Criteria

- [ ] A mutational-neighborhood indicator reports the silent, changed, and dead fractions per operator and per birth on single-tick and short multi-tick batteries: the founder half inside the gate profile at every closure program-wide, the evolved-genome half in the goal profile.
- [ ] Structural VM edits (insert, delete, replace, motif insertion, block and slice copies) preserve every surviving control-flow reference outside the edited span, verified by property tests, and no single operand-level VM event redraws more than one field (opcode replacement stays a separate macro operator).
- [x] Adding or copying a graph compute node, or adding an input reference, is silent on the founder battery at least 95% of the time, and new edges can reach every sensor sub-value. (T11.F03 closure, 2026-09-05: `AddInternalGraphNode`, `CopyInternalNode`, and input-reference `Add` each read 1.00 silent on the stored gate report, and `random_graph_source` draws every sub-index; the no-regression rule keeps this true at later closures.)
- [ ] At production defaults, mutated births are behaviorally dead at most 5% of the time and single-event births are silent at least 60% of the time, with every behavior-changing operator family still enabled.
- [ ] Persistent graph state and eligibility traces advance on an explicit world-tick clock, verified by fixtures across relaxation-pass limits, disconnected-node additions, and skipped module visits.
- [ ] Copying a working module keeps it working, and learned weights follow surviving homologous nodes and edges through structural mutation.
- [ ] Founders reach and retain a useful remembered decision through viable mutations in a bounded delayed-cue task.
- [ ] The node-type contract (references stable by id or remapped on every edit, growth that preserves function when it fires, persistent state that advances once per world tick, mutation delivered in small steps) is recorded in the reference specs, and every backend, existing or added, is checked against it by property tests and the neighborhood indicator.
- [ ] A new route branch is born pointing at working structure and carrying its own gate write, so it is silent when it fires and can become conditional in one event; retargeting draws a nearby destination; removing a node or a branch is not predominantly lethal; a node runs at most once per tick; and every topology operator sits in the growth-versus-connection taxonomy with a named owner.
- [ ] Executed mesh node counts, route variation with input, hop-cap hits, and total and reachable node counts are recorded at every closure, and every mesh-layer claim states the generation depth it was read at.
- [ ] Every floor above is met by the close of T11.F10, and from T11.F01 onward no closed feature anywhere in the program lowers an indicator component below the previous closed feature's reading unless its spec predeclared and justified the change.

## Executable Features

- [x] **T11.F01 — Mutational Neighborhood Indicator** — Depends on: T01.F12
  - Goal: One step away. At every closure, read how often a single mutation leaves a brain acting like its parent, acting differently, or not acting at all, on the founder and on evolved genomes, with floors predeclared before any repair; observation only.
- [x] **T11.F02 — VM Structural Mutation Semantics** — Depends on: T11.F01
  - Goal: Gene insertion, deletion, and duplication. Adding, removing, replacing, or copying instructions keeps every surviving jump pointing where it did, an operand mutation changes one field by a small step, terminals stay terminals, and a register count never aliases registers.
- [x] **T11.F03 — Function-Preserving Graph Growth** — Depends on: T11.F01
  - Goal: New neural connections. A compute node joins the circuit disconnected or by splitting an existing edge with its function preserved, copies never rewire live nodes, and new edges can reach every sensor sub-value.
- [x] **T11.F04 — Mutation Supply and Neutral Scaffold** — Depends on: T11.F02, T11.F03
  - Goal: Point mutations one at a time. Mutation arrives mostly as single events at a provisional mean of about 0.55 requested events per birth, inactive structure receives the same target opportunity as live code, and persistence is re-read after the change.
- [x] **T11.F05 — Temporal Controller Fixtures** — Depends on: None
  - Goal: Check the brain's building blocks with small delayed-cue, memory-retention, and delayed-reward fixtures on constructed controllers, recording capability and measured gaps before interpreting evolution.
- [x] **T11.F06 — Graph Memory Clock** — Depends on: T11.F01, T11.F05
  - Goal: Neural timescales. Remembered graph state, including what a backward edge reads, advances once per world tick, so extra settling passes or disconnected computation cannot speed up forgetting.
- [ ] **T11.F07 — Reward Trace Clock** — Depends on: T11.F05
  - Goal: Synaptic eligibility. Recent activity fades with elapsed world time and influences later learning through one explicit, calibrated reward-update rule.
- [ ] **T11.F08 — Function-Preserving Duplication and Module Growth** — Depends on: T11.F02, T11.F03, T11.F06
  - Goal: Gene duplication. Copying a working module keeps it working, so complexity can grow by copy and divergence as in real genomes.
- [ ] **T11.F09 — Learned-State Inheritance Integrity** — Depends on: T11.F07, T11.F08
  - Goal: Inherited neural adaptation. When learned weights are heritable, structural mutation preserves their association with surviving connections and initializes new connections explicitly.
- [ ] **T11.F10 — Memory-Motif Evolvability from Founders** — Depends on: T11.F04, T11.F09
  - Goal: Can memory be found? In small temporal tasks, measure whether founders reach and retain useful remembered decisions through viable mutations before testing seasonal ecology.
- [ ] **T11.F11 — Label-Addressed Control Flow** — Depends on: T11.F02, T11.F08
  - Goal: Conditional on the T11.F01 reading after T11.F02 and T11.F08. Promoter sequences, not positions: a jump finds its target by an evolvable label with nearest-match resolution, so duplicated or shifted code keeps working without per-operator reference repair.
- [ ] **T11.F12 — Neutral Network and Robustness Characterization** — Depends on: T11.F01, T08.F02
  - Goal: Slack in the genome. How much neutral structure absorbs mutation and keeps function intact, distinguished from unreachable bloat.
- [ ] **T11.F13 — Mutation-Rate Characterization** — Depends on: T11.F10
  - Goal: Mutation–selection balance. Measure which mutation rates support discovery and retention under named environments and time horizons, and use those readings to inform production defaults and inherited-rate bounds.
- [ ] **T11.F14 — Mesh Execution Observability** — Depends on: T11.F01
  - Goal: Generations, not ticks; executed, not reachable. Record what a lineage's mesh actually runs, whether its route ever varies with the input, how often it loops to the hop cap, and how many generations the goal profile reaches, so mesh-layer claims are read at a depth and in a unit that can support them; observation only.
- [ ] **T11.F15 — Mesh Routing Connection Semantics** — Depends on: T11.F02, T11.F03, T11.F04, T11.F14
  - Goal: A synapse forms with its own trigger. A new route branch is born pointing at something that already works and carrying its own bid, so it is silent at birth and conditional from its first win; retargeting lands near, removing a node or branch is not usually lethal, and a node runs at most once per tick.

- Node-type contract. The mesh cannot inherit evolvability from any one representation the way NEAT, Markov brains, or SignalGP do inside theirs, so it must guarantee four properties in its own contract, and the audit is the record that they were never written down: (1) every internal reference is stable by id or remapped on every edit (T11.F02 for VM jumps; T11.F03 and T11.F08 for graph indices and copies; T11.F11 if labels are adopted); (2) every growth operator preserves function at the moment it fires (T11.F03, T11.F08); (3) every piece of persistent state advances once per world tick (T11.F06, T11.F07); (4) mutation supply arrives as small steps (T11.F02 operand steps, T11.F04; T11.F15 for the topology connection operators). Record the contract as a section of `docs/reference/v3-mutation-spec.md` with pointers from the VM and graph backend specs when T11.F02 lands, and extend it as later features refine it. A new node kind (a gate bank in the Markov-brain style, a further network flavor) is welcome as a bounded T11 feature that meets the contract and the floors and carries its applied energy cost; it needs no measured gap, only the contract. Replacing the mesh itself, or fan-out that runs several nodes per tick under a hop budget, does need a measured gap: keep the single-successor chain, since nothing in the audit shows the chain blocks cognition, and shared memory already serves as the side channel between nodes. The 2026-09-06 mesh note confirms the chain is not the block (Tangled Program Graphs grow deep modular controllers on the same one-path argmax) and finds the measured gap elsewhere: a route branch is two halves in two genome domains, the `RouteTarget` in the topology and the gate write inside the backend, and no operator creates both, so evolved meshes never route conditionally. The T11.F03 taxonomy leaves `AddRouteTarget`, `MutateGateBias`, `RetargetNodeTarget`, `RemoveRouteTarget`, `RemoveNode`, `SwapNodeBackend`, `ChangeEntryNode`, and `SwapRouteTargets` in neither class with no owner; T11.F15 places and owns them. The one executor change that note justifies by a measured gap is the single-visit rule (a node runs at most once per tick, replacing the mesh spec's "self-loops are legal"), which T11.F15 also owns. T11.F06's clock decision is what makes the graph node a true recurrent-network flavor. The reconciliation with the original mesh vision is in the companion document.
- Floors and the no-regression rule. The floors below were predeclared on 2026-09-04 from the audit's founder battery. The T11.F01 spec fixes their final values from the fuller battery (multi-tick sequences, evolved genomes) before any repair lands, and may set a value below the audit's only with a recorded reason; after T11.F01 closes no floor is loosened. Floors are track-level: they are met by the close of T11.F10, not by each repair, because the dead and single-event floors cannot be reached before the supply change in T11.F04. The per-feature rule is no regression, mirroring the compute-regression rule: the founder half of the indicator runs in the gate profile for every closed feature program-wide, since any feature can change mutation or runtime semantics, and no closed feature lowers an indicator component below the previous closed feature's reading unless its spec predeclared and justified the change. Each T11 repair feature names, before implementation, the components it expects to move and in which direction. Floors: (a) inserting one `Noop` with jump repair, or copying a block into an unreachable span, leaves the battery trace identical for any program whose jumps target in-range instructions and whose execution stays under the step cap (property tests); (b) memory-motif insertions are at least 80% silent on the founder; (c) graph add-node and copy-node and input-reference addition are at least 95% silent; (d) mutated births at production defaults are at most 5% dead; (e) single-event births are at least 60% silent. Floors are minimums that say structural growth is usually neutral; they are not a score, and no feature may meet one by disabling or down-weighting a behavior-changing operator family. Every T11 feature that changes simulation semantics re-reads the indicator and runs `cargo test -p v3-core --test viability` before closure, and reports any persistence shift against the T01.F11 baseline rather than hiding it. Floors (a) through (e) cover the VM, graph, and per-birth readings and name no topology operator; rather than retro-fit the 2026-09-04 list, T11.F15 predeclares its own targets for the mesh routing operators against the counterfactual readings in the 2026-09-06 companion note, and those targets then fall under the same no-regression rule.

- T11.F02 owns VM insertion, deletion, replacement, memory-motif insertion, and block and slice copying in `crates/v3-core/src/mutation/vm/operators.rs` and the jump semantics in `runtime/vm.rs`. Today no splice recomputes the offsets of jumps that straddle it; the remapped block copy adds the positional delta to every jump in the block (internal targets should keep their offset and external ones need the opposite sign); raw-field mutation redraws every operand of an instruction and turns a jump offset into a random i32; terminal and no-op instructions are rewritten into random pushes; and a register-count decrement aliases the top register onto register 0 through the modulo resolution. Its spec defines internal, external, deleted, and wrapped-target policies for every splice (a jump whose provisional target is out of range wraps by program length at runtime, so the remap computes the absolute target under the old length and re-encodes it under the new one), single-field operand steps with a bounded jump nudge, register growth or remapping instead of aliasing, and register slack in the founder, with property tests for surviving references and the T11.F01 battery for behavior. Preserving references does not require every mutation to preserve behavior.
- T11.F03 replaces the current `add_compute_node` in `crates/v3-core/src/mutation/graph/operators.rs`, which adds one random-weight edge per sub-value of every input reference to random surfaces including the action and execute gates. Growth options are a disconnected node, a node with one bootstrap edge, and a NEAT-style split of an existing edge whose incoming weight is 1 and outgoing weight is the old weight. `copy_compute_node` stops adding a backlink into a live node, and new edges sample sub-indices through `mutation/compound.rs` instead of fixing them at 0. The feature also fixes the operator taxonomy the contract relies on: growth operators (add compute node, copy compute node, copy subgraph, add input reference, mesh add, splice, and copies) must be neutral at the moment they fire, so the input-reference `Add` operator, which today wires the new reference into a random surface, leaves it unwired or wires it only into a disconnected node; connection and parameter operators (add, retarget, or remove edge, copy edge bundle, swap kind, mutate parameter, input-reference swap and raw field) may change behavior and must do so in one small step. Measure retained behavior and subsequent activation; a permanently disconnected node is the expected neutral first step, not success by itself. Do not import NEAT's speciation or global fitness sharing into ecological selection; spatial population structure is Petri's protection of new structure, and whether it suffices is what the indicator and T11.F10 measure.

- T11.F06 (was T09.F10) separates persistent temporal updates from within-tick graph relaxation. Current `runtime/cgp/execute.rs` zeroes every compute output at the start of each dispatch and advances stateful operators on every relaxation pass, including passes prolonged by disconnected nodes, so a backward edge reads the previous pass rather than the previous tick and a `DecayIntegrator`'s timescale depends on unrelated structure. Its spec decides between persisting converged outputs across ticks and replacing relaxation with one synchronous update per tick in which backward and self edges read last tick's outputs, as NEAT activation and Markov brains do; the second makes every recurrent edge a one-tick memory element, gives the explicit clock this feature exists for, and cuts per-tick graph cost from at least three passes to one. Define state visibility, repeated dispatch within a tick, and energy-exhaustion rollback; verify memory trajectories across pass limits and disconnected-node additions while preserving combinational computation; audit realized energy and compute costs separately. Changing pass semantics changes per-tick graph cost and the meaning of the `graph_relax_iters` work counter, so the spec predeclares the expected compute change and records the counter's new definition in the benchmark series rather than comparing across it silently. The goal profile's memory-sensitivity indicator perturbs current shared memory only; when graph outputs persist across ticks, this feature adds a versioned indicator component that perturbs persisted graph state and previous-tick slots, coordinated with the intervention set T09.F08 defines, so memory that moves into graph state does not vanish from the reading. This feature does not replace the VM or add a new controller family.

- T11.F15 owns the topology connection operators and the mesh executor's visit rule. Measured on evolved genomes in the T11.F06 goal report, the topology family reads 0.110 changed against 0.182 dead where VM reads 0.306/0.004 and graph 0.326/0.000; `AddRouteTarget` and `MutateGateBias` read 1.000 and 0.992 silent, `RetargetNodeTarget` 0.385 dead, `RemoveNode` 0.821 dead, `RemoveRouteTarget` 0.657 dead, `SwapNodeBackend` 0.392 dead, and `RewriteNodeId` (14.8% of mesh supply) is a semantic no-op. On goal seed 11 at 2,000 ticks, 0 of 11,024 evolved creatures route conditionally on the 48-scenario battery although 23% execute a node carrying a second branch. The note's cumulative counterfactual (its Appendix B) isolates the repair: activation-neutral destinations alone leave route variation at zero; a branch born with its own gate write (a `RouterGate` edge on a graph node, a `WriteRouteGate` inserted with reference repair on a VM node) onto a detour or paralog destination seeded tied-but-losing raises it to 5 to 8% of drift lineages and, with the single-visit rule, to 16.3% of 11,242 evolved creatures at the same population and horizon with hop-cap loops at zero. The feature adopts that shape: branch with bid onto an activation-neutral destination; `CopyNode` as a paralog hung off a predecessor; `RetargetNodeTarget` drawing from the successor's targets or the node's other targets and never itself; `RemoveNode` preferring unreachable nodes and otherwise bypassing (the inverse of splice); `RemoveRouteTarget` removing losing branches only; `RewriteNodeId` retired; `SwapNodeBackend` split into a neutral add on a losing branch plus a small-step swap; `ChangeEntryNode` kept as an explicit macro at weight 1; and single-visit routing recorded in `v3-mesh-execution-spec.md` in place of the self-loop sentence. It places all eight operators in the growth-versus-connection taxonomy in `v3-mutation-spec.md` and predeclares its indicator directions from the note's Section 5: route variation above zero on the evolved half, executed count up, hop-cap hits to zero, removal and retarget dead fractions down, founder rows unchanged except the retired no-op, per-birth dead fraction not up. The spec decides the bid's source distribution (the production sampler draws shared memory a fifth of the time, which never varies on a fresh battery). It adds no addressing scheme (see T11.F11), no fan-out, no per-hop cost, and no persistent routing position; those stay recorded in the note with their triggers.
- Rate research rechecked 2026-09-05: [Avida's mutation documentation](https://github.com/devosoft/avida/wiki/Mutation-settings) distinguishes a display-oriented 0.0075 per-copy default from the commonly used experimental 0.0025. [Clune et al. 2008](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1000187) found that selection on rugged landscapes could favor mutation rates below the long-term adaptation optimum; [Kumawat et al. 2025](https://pubmed.ncbi.nlm.nih.gov/39739809/) found that environmental change could support elevated rates and useful alternative phenotypes. Neither establishes a numerical Petri optimum. Separating delivery repair, fixed-rate characterization, and inherited policy preserves an interpretable control for each decision.
