# T11 — Brain Genotype-Phenotype Map

**Status**: In Progress
**Last updated**: 2026-09-23
**Master**: [Program Roadmap](../roadmap.md)

## Goal

Petri's brain is a heterogeneous mesh: nodes of any compute kind that read
sensors, shared memory, and an upstream bus, steer which node runs next, may
write memory as a side effect, and commit one action or a queue each tick.
Make the map from that genome to behavior evolvable: a brain can gain an
instruction, a node, an edge, or a memory motif and usually still act as its
parent did, so lineages accumulate structure through neutral and near-neutral
steps, while live internal state advances with computation and eligibility
decays with world time. Record these properties as the contract every node kind
must meet. Repair the existing VM and graph kinds against it first, and change
a representation only where the neighborhood reading still shows a gap.

## Executable Features

- [x] **T11.F01 — Mutational Neighborhood Indicator** — Depends on: T01.F12
  - Goal: One step away. At every closure, read how often a single mutation leaves a brain acting like its parent, acting differently, or not acting at all, on the founder and on evolved genomes, with floors predeclared before any repair; observation only.
- [x] **T11.F02 — VM Structural Mutation Semantics** — Depends on: T11.F01
  - Goal: Gene insertion, deletion, and duplication. Adding, removing, replacing, or copying instructions keeps every surviving jump pointing where it did, an operand mutation changes one field by a small step, terminals stay terminals, and a register count never aliases registers.
- [x] **T11.F03 — Function-Preserving Graph Growth** — Depends on: T11.F01
  - Goal: New neural connections. A compute node joins the circuit disconnected or by splitting an existing edge with its function preserved, copies never rewire live nodes, and new edges can reach every sensor sub-value.
- [x] **T11.F04 — Mutation Supply and Neutral Scaffold** — Depends on: T11.F02, T11.F03
  - Goal: Point mutations one at a time. Mutation arrives mostly as single events at a provisional mean of about 0.55 requested events per birth, inactive structure receives the same target opportunity as live code, and persistence is re-read after the change.
- [x] **T11.F05 — Temporal Controller Fixtures** — Depends on: None
  - Goal: Check the brain's building blocks with small delayed-cue, memory-retention, and delayed-reward fixtures on constructed controllers, recording capability and measured gaps before interpreting evolution.
- [x] **T11.F06 — Graph Memory Clock** — Depends on: T11.F01, T11.F05
  - Goal: Neural timescales. Graph state has an explicit committed-state clock; T19.F02 supersedes this feature's original once-per-world-tick update with live per-visit updates, while eligibility decay follows world time.
- [x] **T11.F07 — Reward Trace Clock** — Depends on: T11.F05
  - Goal: Synaptic eligibility. Recent activity fades with elapsed world time and influences later learning through one explicit, calibrated reward-update rule.
- [x] **T11.F08 — Function-Preserving Duplication and Module Growth** — Depends on: T11.F02, T11.F03, T11.F06
  - Goal: Gene duplication. Copying a working module keeps it working, so complexity can grow by copy and divergence as in real genomes.
- [x] **T11.F09 — Learned-State Inheritance Integrity** — Depends on: T11.F07, T11.F08
  - Goal: Inherited neural adaptation. When learned weights are heritable, structural mutation preserves their association with surviving connections and initializes new connections explicitly.
- [ ] **T11.F10 — Memory-Motif Evolvability from Founders** — Depends on: T11.F04, T11.F09, T11.F18, T13.F06, T11.F19, T19.F06
  - Goal: Can memory be found? In small temporal tasks, measure whether founders reach and retain useful remembered decisions through viable mutations before testing seasonal ecology.
- [ ] **T11.F11 — Label-Addressed Control Flow** — Depends on: T11.F02, T11.F08
  - Goal: Conditional VM-only option, unscheduled: promoter-like labels may address a demonstrated VM control-flow reference defect that local reference repair cannot adequately resolve; sensor and mesh addressing are outside its scope.
- [ ] **T11.F12 — Neutral Network and Robustness Characterization** — Depends on: T11.F01, T08.F02
  - Goal: Slack in the genome. How much neutral structure absorbs mutation and keeps function intact, distinguished from unreachable bloat.
- [ ] **T11.F13 — Mutation-Rate Characterization** — Depends on: T11.F10, T11.F20
  - Goal: Mutation–selection balance. Measure which per-unit mutation rates support discovery and retention under named environments and time horizons, and use those readings to inform the production default and T08.F05's inherited-rate bounds.
- [x] **T11.F14 — Mesh Execution Observability** — Depends on: T11.F01
  - Goal: Generations, not ticks; executed, not reachable. Record what a lineage's mesh actually runs, whether its route ever varies with the input, how often it loops to the hop cap, and how many generations the goal profile reaches, so mesh-layer claims are read at a depth and in a unit that can support them; observation only.
- [x] **T11.F15 — Mesh Routing Connection Semantics** — Depends on: T11.F02, T11.F03, T11.F04, T11.F14
  - Goal: A synapse forms with its own trigger. A new route branch carries its own bid and points at working structure, retargeting lands near, and removal is not usually lethal; the original single-visit restriction is retired by T19.F02.
- [x] **T11.F16 — Drift-Depth Indicator** — Depends on: T11.F14
  - Goal: Generations, not ticks, read at depth. Walk lineages from the founder under the production mutation engine to generations 250, 1,000, and 2,000 and read what their meshes execute and how often a birth still changes behavior, in seconds at every closure, so the program sees whether the substrate keeps evolving past the goal profile's 22 generations; observation only.
- [x] **T11.F17 — Executed-Biased Mutation Targeting** — Depends on: T11.F04, T11.F15, T11.F16
  - Goal: Expressed genes mutate more. Node-internal mutation events land mostly on the nodes a creature's brain actually ran in its recent ticks, so the functional core keeps receiving mutations however much silent scaffold surrounds it, while the number of events per birth and the scaffold's own drift stay as they are.

- [x] **T11.F18 — Backend-Neutral Mesh Node Growth** — Depends on: T11.F15, T11.F17
  - Goal: Developmental variation in new neural tissue. A creature can grow either kind of brain module along a working decision path without losing its current behavior, so graph computation has the same direct opportunity as VM computation to enter an evolving controller.
- [x] **T11.F19 — Per-Unit Mutation Supply** — Depends on: T11.F04, T11.F17, T03.F08, T14.F12
  - Goal: Copy errors per base. Every `genome_size()` unit a parent carries is an independent chance of one mutation event at birth, so the expected number of events grows with the genome instead of being a fixed count per birth; the founder's supply is unchanged, a larger genome pays its size in exposure, and the per-birth minimum, maximum, and continuation rule are retired.
- [ ] **T11.F20 — Per-Birth Supply Rule Retirement** — Depends on: T11.F19
  - Goal: One way to mutate. The per-unit draw is the only mutation-count rule in the engine, the config, the panel, and the reference specs; the drift walk and the recruitment-paths experiment hold their fixed exposure as an instrument constant, not as a second configurable rule. Removal of a rule with no natural analog; the per-unit draw's analog is stated at T11.F19.
- [x] **T11.F21 — Per-Direction Motor Output** — Depends on: T11.F14, T11.F15, T11.F18
  - Goal: A motor map with winner-take-all selection. A movement action (Move, Reproduce, StealEnergy) may carry an eight-slot direction bank, one bid per neighbor cell, and the body commits the direction with the highest bid, ties to the scalar-decoded direction, so one edge from a neighbor-food slot or one negative edge from a neighbor-barrier slot is a complete, selectable steering step in either backend; a genome that writes no bank decodes its direction from the scalar parameter exactly as today, the founder writes none, and no sensor, operator family, or config value is added. The form, decode rule, both backend shapes, the `steering-v1` readings, and the predeclared directions are fixed in the [motor output encoding research note](../strategy/motor-output-encoding-research-2026-09-16.md), "Contract for T11.F21"; the reading it repairs is the [live survey](../strategy/live-survey-2026-09-16.md) (one sensor-to-direction rule in 400 generations, 0 of 12,501 barrier avoidances). Predeclared: on the evolved half, the exact-hit fraction on a single food neighbor rises above the 12.5% chance level and the barrier-avoidance fraction above zero; founder rows and the gate trajectory unchanged; the goal trajectory is expected to diverge and its epoch to be re-pinned; changed-per-birth not down. If seeking and avoidance stay at chance while banks are being written, the note's finding 7 (the ecology, not the encoding, keeps steering rare) is the recorded explanation.
- [x] **T11.F22 — Meaning-Stable Input References** — Depends on: T11.F08, T13.F03
  - Goal: A neuron keeps the afferents it was wired with; a receptive field may drift within its modality but never changes modality. A node's sensor references keep their kind for the node's life and its descendants': the reference swap draws only within the same read class and compound width (a food ring may become a fruit ring, never a scalar or a barrier ring), removal becomes a prune of references nothing reads, so a consumer never loses its sensor and indices never shift under it, `Add` stays the one-event neutral way to reach a new sensor, new nodes draw their references at creation, and copies inherit. The evidence, the option comparison, and the contract are in the [input reference stability research note](../strategy/input-reference-stability-research-2026-09-16.md): in the running world `InputRef.Swap` and `Remove` are the two lowest-value non-topology operators (helpful share 0.446 and 0.457 against a 0.50 to 0.53 baseline) and at the same time supply 38% of all behavior-changing events, so the feature narrows their step rather than retiring them. Predeclared: dead-per-birth not up; changed-per-birth may fall by no more than the bound the spec computes from the cross-kind share of today's swaps plus `Remove`'s 12.5%; the swap's live helpful share rises toward the operator baseline at closure. Full retirement (the note's option B) is the recorded follow-on arm, not part of this feature.
- [x] **T11.F23 — Scale-Relative VM Constant Steps** — Depends on: T17.F01
  - Goal: A mutation nudges a number by a share of what it is, not by a fixed amount. `VmConstantMutation` today adds a uniform draw from [−1, 1] to one constant of a VM program's pool regardless of the constant's scale (`crates/v3-core/src/mutation/vm/operators.rs`, `scale = 1.0`), while every graph parameter step is ±0.1 and the brain is moving onto the unit scale (T17.F01 made the reproduce transfer a fraction in [0, 1]; T17.F02 and T17.F03 follow). On the founder's transfer constant of 2/3, about 17% of draws clamp the line sterile at 0 and about 33% clamp it semelparous at 1; the step is the whole width of the slot. Natural analog: mutational effects on a quantitative trait scale with the trait's magnitude (proportional-effect and log-scale mutation models; evolution strategies' step sizes track the parameter, not a global unit). The step becomes `c += U(−0.1, 0.1) × max(|c|, 1)`: ±0.1 of the constant's magnitude, never less than ±0.1 absolute, so a unit-scale constant moves as a graph parameter does and a raw-scale constant (an age gate of 20, a raw energy threshold of 32) moves proportionally; the empty-pool draw in [−1, 1] is unchanged; no operator weight, sensor, or config value is added. Evidence: T17.F01's spec surfaced the sterile and semelparous shares, and its goal run read `founder_changed_per_all_births` falling against a predeclared rise. Predeclared: the T11.F14 changed/silent/dead founder readings and the goal trajectories move (epoch re-pin recorded); the founder's transfer-slot sterile and semelparous shares under one `VmConstantMutation` fall to zero, read from the founder battery before and after; goal births per creature-tick read before and after with no sign.

- [ ] **T11.F24 — Stable Parent Membership During Mutation** — Depends on: T11.F17, T13.F01
  - Goal: Mutations follow the tissue that existed in the parent: later events in one birth retain correct parent-reachable and parent-executed membership after deletion or addition changes the child's node indices.
- [ ] **T11.F25 — Meaningful Action-Parameter Targets** — Depends on: T19.F04
  - Goal: Variation reaches expressed action traits: new Graph and VM parameter connections target fields the body's current action decoder actually consumes.
