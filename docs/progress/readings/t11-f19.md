Skipped: consolidating the ~40 test sites that add
`per_unit_supply_enabled = false` before `mutation_probability` (the pattern
predates the feature; one line per site); a shared `MutationConfig` helper
behind `forced_legacy_supply` and `proposal_mutation_config` (two callers with
different base configs, and the spec names `proposal_mutation_config()`); the
`// per_unit_supply_enabled: bool, no normalization needed.` comment in
`normalize` (it follows the file's existing convention for boolean fields);
the frontend `Rate / Unit` `max: 0.1` against the backend clamp to `[0, 1]`
(a product choice, not a cleanup).
