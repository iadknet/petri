## T13.F05 recruitment-path replay (invariant 7)

`vm_unprepared` re-derived from the same starting form with the existing
operators, `MAX_PATH_EVENTS` 6 and `SEARCH_RANGE` 1,000,000 unchanged, every
other step's predicate unchanged. The two-event constant walk (`direction_half`
≥ 0.5, `direction_east` in [1.5, 2.5)) is unreachable: from 0.0 the step is at
most 0.1 per event until |c| ≥ 1, at least fifteen maximal draws to 1.5. The
shorter route through another operator: one `VmInstructionMutation` replace
of the direction constant's `LoadConst { dst: 3, const_idx: 1 }` (program
index 4) with `Add { dst: 3, a: 0, b: 0 }`, doubling the cue register into
the direction register (the east code 2, as `vm_blank`'s `double_to_east`
step computes it). Constants, register count, program length and every other
instruction are required unchanged.

| Step | Event | Old seed | New seed |
| --- | --- | ---: | ---: |
| `ring_added` | `InputRef.Add` | 68 | 68 |
| `read_ref_idx_1` | `VmInstructionRawFieldMutation` | 94 | 94 |
| `read_sub_idx_1` | `VmInstructionRawFieldMutation` | 72 | 72 |
| `read_sub_idx_2` | `VmInstructionRawFieldMutation` | 223 | 223 |
| `direction_half` | `VmConstantMutation` | 13 | (removed) |
| `direction_east` | `VmConstantMutation` | 13 | (removed) |
| `direction_doubled` | `VmInstructionMutation` | (new) | 205,178 |
| `activated` | `Topology.SwapRouteTargets` | 0 | 0 |

The seed is the module's own first-accepted search
(`recruitment_paths_seed_search_finds_the_pinned_seeds` asserts it). The
route is six events, so `vm_unprepared` qualifies and its `GrowthGap`
(`length` 7, "the direction constant moved twice") is removed; qualified
forms 6 → 7 (`vm_unprepared` joins), `qualified_paths().len()` stays 9, the
blank forms stay recorded growth gaps. This one-event replace was available
to the parent operators too: the T11.F22 record's "no six-event route exists
with the existing operators" was the constant-walk reading, not a search of
the other operators.
