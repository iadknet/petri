[design review](t30-design-review.md) finding 5 (the row's origin),

| Question | Options | Chosen, and why |

| Where `splitmix64` lives | `contracts/hash.rs`; `rand_xoshiro::SplitMix64` (`seed_from_u64(x).next_u64()` is the same finalizer); `ledger` or `config` | `contracts`: the architecture lists deterministic hashing among the contracts values "that no domain above owns"; a crate dependency for four lines of a stable finalizer fails research-first-planning's own guardrail, and its byte-identity with today's function would be one more thing to pin. |

| Verification profile | `none` (a code move cannot change a trajectory); `gate`; `gate + goal` | `gate`: the track's success criterion is that no pin moves, and the moved hash sits under every food-growth draw of every tick; the gate's deterministic blocks against the epoch are that reading, in seconds.
