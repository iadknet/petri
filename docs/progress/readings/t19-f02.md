## Before reading: drift walk on the unflipped executor

Method: the T19.F02 instrumentation (`WorkCounters.pass_cap_hits`, the
`cycle_carrying` / `revisiting` / `productive_cycle` lineage classes, and the
births probe's cycle partition) applied on top of `aa467eef` with the executor
still running the visited filter and the tick-start snapshot. A throwaway
`v3-cli` integration test (`cargo test --release -p v3-cli --test
drift_probe_tmp -- --ignored --nocapture`, deleted after the run, nothing of it
committed) built each goal world exactly as the goal profile does
(`resolve_config` over the checked-in recipe, then `build_config` with
`goal_profile_params()`), generated the battery for the world's food-type
count, and ran `neighborhood::drift::observe` from the V3Alpha1 founder at
`DriftSizes::PRODUCTION` (50 lineages, 20 birth lineages, 100 births per
checkpoint, checkpoints 0 / 22 / 250 / 1,000 / 2,000). Release build, host
Apple M1 Pro, 2026-09-22, about 4 s per world.

Identity check: every world's `config_digest` equals the pinned T19.F01
recipe digest, and every pre-existing column (`executed_nodes`,
`hop_cap_hits`, `route_varying_lineages`, and the births `any_events`
trials / silent / changed / dead) equals the stored
`docs/progress/features/t19-f01-per-tick-hop-ramp-goal.json` `drift_depth`
row for the same world and depth, all 15 rows.

Definitions read here: `cycle_carrying` counts lineages whose reachable
mesh has a node that can route back to itself (self-targets included);
`revisiting` counts lineages with some battery execution that dispatched a
node more than once; `productive_cycle` counts lineages with some execution
that dispatched a cycle node and returned an action list other than
`[NoOp]`. The births partition splits the classified births (`any_events`)
by whether the offspring's reachable mesh carries a cycle; zero-event births
are not classified and belong to neither side.

Orchards in grassland (seed 11) and Confluence (seed 33) share a mutation
config and food-type count, so their walks are identical; Canyon country
(seed 22) has one food type.

Reading: under the visited filter no lineage revisits and no pass caps, so
the cycle-carrying lineages (up to 9 of 50 at depth 2,000) execute their
cycle nodes at most once per tick; three lineages per world still return a
non-`NoOp` list from an execution that dispatched a cycle node. Cycle-carrying
offspring are almost entirely silent (2 changed of 132 at Orchards depth
2,000, 1 of 59 at Canyon depth 250, none dead), the births denominator is
2,000 per checkpoint (20 lineages by 100 births).
