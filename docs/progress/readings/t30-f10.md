# T30.F10 — One Operator Catalog: readings

## Options weighed at planning (2026-10-28)

Inputs: the T30 row and its Notes entry for F10 (the user's direction of
2026-10-27, "Draft rows A, B and C in T30"; the [F10–F12 design
review](t30-f10-f12-design-review.md), rounds 1–3 clear on F10),
`docs/architecture.md` rules 1–4 and section 3 (mutation samples; one owner
per concept), the T25 row for F12 (depends on F10: it adds report fields
to the engine path), the T30.F05 note (the test-only samplers are F05's,
user 2026-10-27), the T30.F09 note (recruitment paths leave core) and the
code on `ac3747005`. The decision is a type and a control-flow refactor
inside one crate. Rust's own idiom for "one catalog, derived facts" is a
closed enum nesting the domain enums with `From` impls and `const`
tables (architecture rule 3: "a variation is a closed enum whose behavior
lives in one module"); the crate already holds the nested shape in
`neighborhood/recruitment_paths/qualification.rs:40-45` (`ProductionEvent`;
the module left with T30.F09 before this feature closed, see the rebase
note at the end).
`strum`'s `EnumIter`/`IntoStaticStr` would derive the `ALL` lists and key
strings, but the workspace carries no enum-iteration crate (`Cargo.toml`),
the four `ALL` lists already exist with compile-time length guards, and a
dependency to avoid four `const` arrays fails the research guardrail; not
adopted. serde's `into`/`try_from` container attributes (serde 1.0,
already a dependency) give the string form without a hand-written
`Serialize`, left to the implementer.

Scale on `ac3747005`: `MutationOperator` has 69 variants in four tables
(`as_key`, `domain`, `complexity_effect`, `all`; `mutation/types/mod.rs:239-625`);
the domain enums hold 14 + 15 + 35 + 5 variants with their own `ALL`,
`weight` and `complexity_effect`; three key functions (`engine/mod.rs:691-742`)
and `GraphOperator::operator` (`graph/mod.rs:159-197`) map them; the engine's
event loop repeats selection in four blocks (`engine/mod.rs:185-371`);
non-test users of the flat variants outside `mutation/`: `neighborhood/recruitment.rs:117-140`
(`EditSurface::of`), `recruitment_paths/qualification.rs:49-55`,
`recruitment_paths/fixtures.rs:242-243`, `v3-cli/src/bench/bundles.rs:258`,
`tests/reproducibility.rs:245-262`; test files naming variants: 17.
