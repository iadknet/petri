## Data findings the page surfaces

- T14.F07's summary names two comparison references, `t11-f19` (the epoch
  baseline) and `t03-f11`; the previous closed summary, `t02-f04`, is not among
  them because the F07 run predates its rebase. The page walks the closed list
  backward from the current closure and uses the first reference the report
  names, so every headline delta reads "single run, vs T03.F11". Those deltas are
  0 % on every reading: T14.F07's simulation is identical to T03.F11's (final
  populations 9,772 / 11,534 / 14,110 in both), which is what an
  observability-only feature should show.
- The goal-v1 segment of the cost row is drawn against the T11.F17 same-seed
  baseline; T11.F01 seed 11 ran 863 VM steps per creature-tick (T11.F04: 3,047)
  against 24.4 at T11.F17, so those points sit above any scale that keeps the
  goal-worlds segment legible. The row's scale fits the goal-worlds segment and
  draws the out-of-range goal-v1 points as clipped triangles at the top edge,
  with the true value in the hover.
- T14.F07's summary carries no grazing fields; its checkpoints on the grazing
  row read "not measured" and T02.F04's carry the values.
- Canyon's sensor census lists no `FoodHere:1`, `NeighborFoodRing:1` or
  `AreaFoodSummary:1` input (a one-food-type world); the bar panel lists the
  inputs each world's census reports rather than a union.
