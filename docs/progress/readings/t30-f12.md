The decision is where the genome enforces the catalog. The crate already
holds the idiom: `GraphEdge` derives `Deserialize` through
`#[serde(try_from = "EdgeWire")]` (`genome/cgp/edge.rs:46-88`), so a
foreign shape is rejected at the only entry for foreign data and every
in-memory value is valid by construction. serde's `try_from` container
attribute (serde 1.0, already a dependency) is that mechanism; no new
dependency.

| Question | Options | Chosen, and why |
| --- | --- | --- |
| Where the full catalog is enforced | (a) the private sink list has no constructor but the fixed catalog, and deserialization validates it (`try_from`, the `GraphEdge` precedent); (b) a `GraphInvariantViolation` in `check_local_invariants`, run by `validate_graph` at every mutation gate and in debug at every bundle primitive's exit; (c) a fixed-size array keyed by index with a hand-written serde to keep the JSON | (a): after `with_output_sinks` is deleted no primitive changes a sink's kind or the list's length, so the only way to hold another list is foreign JSON; (b) re-checks per mutation event a fact no edit can break; (c) rewrites every reader of `sink.kind` and the serde for no reader's benefit |
| How a sink is found | scan by kind returning `Option` (today); one `OutputSinkKind` → catalog-index map | the index map: the catalog order is fixed, so lookup is total and constant-time; the same map builds the catalog, so its order is written once |
| `plans` | keep `def`, filter present sinks; derive from the set's geometry and the fixed vote catalog | geometry only: on the full catalog the result is identical (Plain: every vote sink in `VoteSink::all()` order, which is catalog order; Ring and Pair: every kind of `DirectedVoteKind::ALL`, offsets 0..8) |
| JSON shape | keep each sink's `kind`; drop it | keep: the genome file and canonical hashes stay byte-identical (T30.F09 invariant 2 pins comparator hashes), and a file stays readable |

Draw-order argument for each removed skip, on the full catalog: `draw_births`'s
empty-plans `Err` and `bundle_sources`'s filter never fire (every set has ≥ 32
plans); `RetargetBundle`'s Plain `others` has 38 entries and its post-draw
`hosts` check is always true; `pick_random_surface` has ≥ 108 candidates, so
`None` and `can_add_edge == false` never occur; `gate_sink` finds every
`RouterGate(slot)` for `slot < MAX_GATE_SLOTS`, the only slots
`free_gate_slot` and `lowest_unused_slot` return (`routing.rs:19-44`).
Each removed branch is one a full catalog never takes, so every draw that
runs keeps its range and order.
