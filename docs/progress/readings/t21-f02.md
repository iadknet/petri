# T21.F02 readings

## Options weighed at planning (2026-09-30)

| Decision | Chosen | Against | Why |
| --- | --- | --- | --- |
| Export path for metrics | snapshot encoded on the simulation thread as one OTLP `ExportMetricsServiceRequest` (`opentelemetry-proto` 0.33.0, feature `metrics`) and offered to F01's bounded queue as one item | `opentelemetry_sdk` metrics API with observable instruments and a `PeriodicReader` on its own thread | the track's bounds, exact per-run counts, drop-when-full and flush limits then hold for metrics without a second export path; a `PeriodicReader` collects on its own clock, reports export failures only through SDK logging, and its handling of a series a callback stops observing is unverified |
| Cadence control | wall-time interval (`PETRI_TELEMETRY_METRICS_INTERVAL_MS`, default 1,000, `0` every tick), plus a snapshot at each transition and at run end | every N ticks | the workload runs about 1,770 ticks/s and the goal world about 9.7, so a tick cadence spans two orders of magnitude in export rate; the track's controls are caps per wall second; the tick gauge in each snapshot keeps the tick axis honest |
| Run list | Loki tables of `run.started` and `run.ended`, plus a Prometheus table of `petri_run_tick` per run in range | a `petri.run.info` gauge with seed, world and build as attributes | the track allows one high-cardinality metric attribute, the run ID; seed and world are already on the `run.started` record |
| Dashboards as source | provisioned JSON in `telemetry/grafana/`, `allowUiUpdates: false` | Grafana-as-code generators (grafonnet, Terraform provider) | two dashboards do not justify a toolchain; the JSON is the reviewed artifact |
| Metric names | OTel dotted names with `_total` stripped, Prometheus's default translation restores it | names pre-flattened to Prometheus form | probed on the pinned image: `petri.run.creature_ticks` (monotonic) stores as `petri_run_creature_ticks_total`, `petri.run.mutation_events_applied_total` is not doubled, unit `s` gives `_seconds_total`, gauges keep their name |
