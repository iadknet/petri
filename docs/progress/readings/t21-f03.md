# T21.F03 readings

## Options weighed at planning (2026-09-29)

| Decision | Chosen | Against | Why |
| --- | --- | --- | --- |
| Span export path | spans encoded on the simulation thread as one `ExportTraceServiceRequest` (`opentelemetry-proto` 0.33.0, feature `trace`) and offered to F01's queue as one item, posted to `/v1/traces` | `opentelemetry_sdk` trace API with `BatchSpanProcessor` and the OTLP span exporter | the track's bounds, exact per-run counts, drop-when-full and flush limits then hold for traces without a second queue; the trace SDK is Beta, its processor has its own queue and reports drops only through SDK logging; F02 took the same path for metrics |
| Phase timing source | a plain-data seam in `run_tick` behind `telemetry-seams`: per-phase offset and elapsed for the last tick, the tick's start and elapsed, population and threads | reconstruct per-tick durations in the binary from `phase_wall_clock` deltas, no `v3-core` change | deltas give durations but not starts: the untimed gaps (energy snapshot, queue shuffle, priority sort) would shift every phase span; the track's Boundary note names phase timings as a seam; the seam's per-tick cost is a handful of stores and one clock read, read by the overhead check against the reference build |
| Sampling policy | a trace accompanies every snapshot (interval, transition, run end) at a tick `run_tick` produced; `PETRI_TELEMETRY_TICK_TRACES=off` disables | an independent trace interval | one cadence keeps the trace's tick equal to a snapshot's tick gauge value, so the dashboard joins them; the snapshot caps already bound it per tick and per wall second; F05 gets a separate lever only if its measurements need one |
| Trace identity | run key's high 64 bits followed by the tick | 128 bits of OS entropy per trace | no entropy per tick, and the trace of any tick is addressable from the run ID and the tick |
| Dashboard reach | a Tempo `spans` table in `Petri / Run` with `select(span.petri.tick, span.petri.sample_policy)` | a `traces` table; a data link from a Prometheus panel to Explore | the `traces` frame hides selected attributes in a `nested` field; the `spans` frame links each row to its trace with the span focused (probe below) |
