| Shape of the own-colour self inputs | three scalar `StaticIntrospectionKey` variants (`OwnRed`, `OwnGreen`, `OwnBlue`); one width-3 compound static key; a `DynamicIntrospection` read | Three scalars: `StaticIntrospection` is scalar everywhere today (`compound.rs:26-28` width 1, `resolve_static`, `Family::of`, the inspector's `SCALAR_LABELS`), so each new key is one arm per reader and no compound-static path is invented; colour is fixed for a creature's life, so a tick-start snapshot is exact.
