## Founder port

The founder's decision node is a graph voting `Eat`, the cardinal `Move` and
`Reproduce` sinks, and `Terminate` (`creature/cgp_founder.rs`,
`build_cgp_founder_decision_graph`). Its measured `genome_size()` is 97 for
V3Alpha1, against 111 for the VM decision node it replaces.

Size is the only lever the port moves in the founder-only run. With node 1
padded by 14 unread input references to the old 111 units, the
`founder_only_trajectory_digest_is_pinned` run reproduces the old birth count
exactly (185 births, final population 0); only the digest moves, through the
energy bits of the compute charge (two or three graph passes per tick instead
of one graph and one VM dispatch). Without the padding the smaller genome pays
14 fewer carrying units per tick and the run reaches 323 births.

| Run (seed 2026, 2,000 ticks, mutation off) | Births | Final population |
| --- | --- | --- |
| Before (`f4835da5`) | 185 | 0 |
| Vote founder padded to 111 units (scratch, not committed) | 185 | 0 |
| Vote founder, 97 units | 323 | 0 |

One founder tick at the defaults: forage with food (`Eat, Move E`) runs three
passes and six hops at graph cost 0.00039; no food (`Move E`) runs two passes
and four hops at 0.00026; `NoDecision` ends both.

## Test fixtures adapted to the pass loop

- `temporal_fixtures` E1 and E2 run with `max_actions_per_turn = 1` (a
  labeled deviation): a voting node is otherwise dispatched again in the
  pass after its commit, doubling the per-tick trace credit they pin.
- `reproducibility` routes each founder's decision node into an injected VM
  node holding the paired slot groups; the founder has no VM node.
- `mutational_neighborhood`: `VmCopyConstantBlock` never applies on the
  all-Graph founder (0 applied), where the audit recorded 100% silent.
- v3-cli occupancy-grid pin moves from seed 3 (now extinct before tick 250)
  to seed 1 (2 creatures on 2 cells).
- v3-cli severe-regression fixtures use `mesh_hops`, since the founder's
  `vm_steps` is zero.
- `gate_profile_has_no_severe_regression_against_series_references` fails
  until the closing commit re-pins the gate epoch: gate `mesh_hops` per
  creature-tick is 4.829716 against the T19.F02 epoch's 2.040238 (+136.7%,
  the predeclared severe rise).
